Run each check, print `<STATUS> <id> <message>`, then `doctor: P pass, W warn, F fail, S skip` and exit 1 on any FAIL. WSL is detected from /proc/version (or FH_DOCTOR_PROC_VERSION) containing "microsoft" and "WSL2"; when it is not WSL, every Windows-only check prints SKIP. The checks:
   - host.wsl: INFO with the kernel string.
   - wsl.version: `wsl.exe --version`; WARN on a 2.9.x WSL version.
   - wsl.mirrored: `cmd.exe /c type %UserProfile%\.wslconfig` must contain `networkingMode=mirrored`.
   - wsl.systemd: /etc/wsl.conf has systemd=true and `systemctl is-system-running` is not "offline".

   - repo.location: FAIL when FH_ROOT starts with /mnt/.
   - env.hostfile: TZ and PREVIEW_HOST_IP are set.
   - secrets.perms: dev/.ha-secrets is 700 and its files are 600 when they exist.
   - clock.skew: FAIL if `date -u +%s` and `powershell.exe -NoProfile -Command "[DateTimeOffset]::UtcNow.ToUnixTimeSeconds()"` differ by more than 60.
   - ports.free: on WSL, `netsh.exe interface ipv4 show excludedportrange protocol=tcp` ranges must not contain 8124 or 8130; `ss -ltn` must not show them held by anything except docker-proxy.
   - net.ip: PREVIEW_HOST_IP is in `powershell.exe -NoProfile -Command "Get-NetIPAddress -AddressFamily IPv4 | Select -Expand IPAddress"`.
   - cert.san: `openssl x509 -ext subjectAltName` of dev/.ha-certs/leaf.crt contains IP:PREVIEW_HOST_IP, `openssl verify -CAfile ca.crt` is OK, and fewer than 30 days of validity left is a WARN.
   - fw.hyperv: `powershell.exe -NoProfile -Command "Get-NetFirewallHyperVRule -Name FamilyHubPreview"`; access denied is a WARN that prints the elevated command.

2. **scripts/windows/setup-host.ps1** (LF, `#Requires -RunAsAdministrator`), with params `-Distro` (default "Ubuntu"), `-RepoPath` (the path inside WSL, default "~/HA-Family-Hub"), `-DailyTime` (default "05:30"), `-RemoteSubnet` (optional, limits the rule's remote addresses) and `-SkipCaImport`. Idempotent steps:
   1. In %UserProfile%\.wslconfig, ensure `[wsl2]` has `networkingMode=mirrored`, after copying the old file to `.wslconfig.familyhub-<yyyyMMdd-HHmmss>`.
   2.    4. Unless -SkipCaImport, run `Import-Certificate` of `\\wsl$\<Distro>\<expanded RepoPath>\dev\.ha-certs\ca.crt` into Cert:\CurrentUser\Root. Only ca.crt, never a key.
